# Jev meta-gradient + Tunix feasibility T0 (research only)

**Purpose:** determine the smallest safe interface between the forward-only K2-Horizon tail estimator and future Tunix agentic policy training.
**Date:** 2026-10-08. **Decided:** operator-approved separate offline research.
**Boundary:** no live model training, no model import/weights, no provider calls, no GPU, no fleet router or quota mutation, no checkpoint promotion.

## Hypothesis, predictions and null
- H0 feasibility prediction: a two-step `probe -> update/abstain` synthetic environment can be tested deterministically without installing Tunix or JAX.
- Later scientific hypothesis (not tested at T0): architecture/weight-sketch-conditioned update-direction ranking can outperform random or fixed policies on heldout tasks at equal wall time and probe budget.
- Null: environment nondeterminism, unbounded/malformed actions, any real inference, or accidental production authority is a failure.

## Methods and interpretation
`scripts/tunix_jev_t0.py` uses a task-id-derived synthetic gradient and an allowlisted two-step action contract. The first step reports exactly one selected synthetic coordinate; the second emits a reward and a terminal flag for fake update/abstention. No real training signal is measured. The reporter checks whether JAX/Tunix are installed **without importing or installing either**, to avoid interference with existing PyTorch/ROCm processes.
Tunix is JAX-based post-training tooling, not itself a forward-only estimator. If used later, a policy may be trained with backprop while the target-model estimator remains forward-only. Do not mistake these claims.

## X1 observation
Five focused CPU environment tests PASS. The two fixed synthetic episodes return rewards 0.75826772 and 0.27795276, which have **no predictive-quality interpretation**. JAX module available: **false**; Tunix module available: **false** on the observed X1 environment. Zero provider calls, token charges, real model weights, production actions.
Status: `OFFLINE_ENVIRONMENT_ONLY`, **Tunix integration itself NOT VALIDATED**.
